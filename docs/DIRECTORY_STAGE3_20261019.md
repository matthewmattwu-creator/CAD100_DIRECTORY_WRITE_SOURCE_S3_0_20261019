## 执行链

人工确认 → 原授权检查 → 源文件范围和SHA核验 → 从快照重算计划 → 同文件整体预检 → 新工作副本 → 再核验原属性 → 修改文字 → 保存 → 新CAD进程重新打开 → 对比保护清单及普通/内嵌文本 → 仅通过项进入成果目录。

保护清单包含主实体流、块定义、表记录和GROUP成员关系。仅对明确目标ATTRIB的文字DXF组1/3放行，其他已导出的项必须一致；实体引用按句柄稳定序列化，坐标/实数按16位小数序列化比较。不将内部缩放主动取整；这不等于DWG全对象二进制或像素级一致性证明。

AutoLISP采用原位entget/entmod方式修改属性列表，依据[Autodesk entmod说明](https://help.autodesk.com/cloudhelp/2019/ENU/AutoCAD-AutoLISP-Reference/files/GUID-C7D27797-247E-49B9-937C-0D8C58F4C832.htm)。Unicode环境要求与[LISPSYS官方说明](https://help.autodesk.com/cloudhelp/2024/ENU/AutoCAD-Core/files/GUID-1853092D-6E6D-4A06-8956-AD2C3DF203A3.htm)相关；本程序不自动修改CAD设置。官方API说明不代替本次真实DWG测试。

## 审阅时需分清

- 原批次替换模板脚本未被目录写入调用。
- 未确认、保留、暂不处理、处理通过是不同状态；同文件含暂不处理时不局部发布。
- 原图签没有属性时，这一版不会生成替代文本。
- 外参文件输出路径问题未解决，本版先明确阻止发布，后续另行设计依赖复制。
- 本机真实AutoCAD读取失败在用户配置初始化，未得到可用提取结果。所有通过数字均来自注明范围的白盒/回放/替身检查，不能表述为真实DWG写入通过。
- 原始creator边界：授权校验、原源文件保护、既有批次功能保留；不将QA授权替身编译进正式包。

## 使用说明

出图100% · 目录校对第三阶段写入试验版 S3.0（2026-10-19）

本次已接入“开始处理”：对已确认的修改生成新DWG副本，再重新打开验收。不是原批次替换图框脚本。
真实DWG写入尚待您的CAD环境验证。本机Core Console在用户配置初始化时失败，尚未进入扫描；不能把本次白盒检查称为真实DWG已经处理成功。

如何测试
1. 将整个压缩包完整解压到新的可写文件夹，运行 CAD-100.exe 或“启动出图100%.cmd”，按原授权进入。
2. 进入左侧“目录校对”，选择“04 模板”所在文件夹，并在目录基准栏选择 L-P-CL-001目录_t9.dwg。
3. 扫描后，逐项审阅准备输出内容。可点“确认全部明确项”；标准园路等关联冲突仍须在下方选择正确目录记录，再点击确认。本次不把样本名称写入生产匹配规则。
4. 点击“开始处理”。本版开始实际写副本，不再只是保存第二阶段计划。处理期间请等待，不能切换页面或关闭窗口。
5. 完成后点击“打开输出文件夹”，查看处理验收报告.txt。只有验收通过且确有修改的DWG放在该目录；一致、保留、暂不处理及失败文件不会另外复制为成果。
6. 在CAD中打开通过文件，对照原图确认图号、图名、字号、位置及图纸内容；完成一次真实DWG验收后，再扩大样本范围。

处理规则
- 源DWG不覆盖；同一DWG内仍有未确认/受阻/暂不处理图签，整份跳过。明确选择“保留原值”的图签可以与同文件其他已确认修改并存，保留项不改。
- 只改原有可写图签属性。缺少属性时不新建文字；不换图签、不移动图框、不解组。
- 保留原属性的字号、位置、对齐和原图签插入点、缩放、旋转；不主动取整150.00001811。写入前后及重新打开后的保护清单有差异则不发布。
- 普通属性值与内嵌可见文字同时验收。支持普通单行属性，以及只有前置字宽/字高指令的内嵌文字；不叠加格式。
- 复杂/分段富文本、字段表达式、长于240字符或含换行的目录内容暂时跳过；锁定图层和隐藏目标属性不自动修改。
- 含DWG外参、外链图像或PDF/DWF/DGN底图的文件，暂时整体跳过。此版不复制外链依赖或更改外参路径，避免输出位置变化导致缺图。
- 需要AutoCAD 2021及以上运行环境；Unicode脚本环境需LISPSYS=1/2。本版不自动修改此设置或重启CAD；如报告提示，按提示在CAD中设置并重启后再试。
- 这是内容与参数验收，不是字体视觉、实际文字边界/溢出、所有DWG数据库对象或像素对比的完整验收。CAD保存可能规范化属性数据，严格清单可能因此拒收；报告会保留现场。

成果及日志
- 成果在程序目录 DirectoryTrialRuns/本轮扫描/DWG输出_时间_编号；第四个按钮直接打开。
- 完整输入快照、人工确认和计划仍保存在本轮扫描目录。
- write_jobs_编号是隔离的工作副本/日志，不是验收成果；失败工作副本可能包含部分临时修改，不应当作完成文件使用。
- 扫描阶段顶部按图签统计；处理结束顶部切换为按文件统计，本次文件=处理通过+已跳过+处理失败。
- 已确认只表示人工确认；处理通过才表示程序保存并重新打开验收通过。完成一轮后需重新扫描，才可调整下一轮决定。

边界与验证
原批次核心、原图框替换脚本、授权源码和更新源码未改。目录写入在界面和后端入口都检查原授权；没有新增免授权启动器。测试包仅沿用前版“不自动更新启动”的试验开关，默认源码保留原更新流程。
白盒检查：31项预检/格式/验收，52项模拟进程编排，17项实际LISP函数逻辑（测试解释器），10项WPF处理结果检查，均通过；原有规则、确认与批次回归通过。模拟程序不是CAD，不能代替真实DWG读写测试。
源码复现入口：先运行 tests/confirmation/run_tests.ps1，再运行 tests/stage3/run_tests.ps1 -SkipBuild -PythonExe <Python3的完整路径>。QA替身仅在tmp生成，正式dist与测试包均不含替身。
