# U1.3 受阻行高亮

出图100% 融合测试版 U1.3（2026-10-19）

修复内容
受阻项在扫描完成、没有点击或选中任何行时，即自动显示整行黄色底色。
上一版目录DataGrid的统一RowBackground覆盖了行样式触发器，只有选中单元格时才显黄；本版移除这一覆盖，与批次处理一样由扫描状态驱动行底色。
普通待确认项仍仅核对结果文字标黄；文件名、图号、图名保持白色。
解决目录关联等受阻问题后取消整行底色，随后仍须人工确认才能进入修改计划。

验证
先在U1.3复现未选中受阻行实际背景为深色 #FF171D22。
U1.3在没有任何行选中时，实际受阻行背景为批次使用的 #E048341B；普通待确认行保持深色。不是只检查数据标志或只截图选中态。
47项确认流程和界面检查通过，原批次统一信息/人员54项通过。
未重新执行原生CAD端到端扫描或处理；目录后端、确认规则、批次处理核心和脚本未改。

使用
完整解压到新文件夹，运行CAD-100.exe或启动出图100%.cmd，按原授权正常进入。
目录扫描完成后直接观察标准园路所在行，无须先点它；下方尚未选择任何行时也应为黄色底色。
右侧未确认/已确认及确认全部明确项保持原规则。目录仍只生成计划，不写入DWG；已确认不代表DWG已生成。
原批次处理功能保留。源码测试入口 tests/confirmation/run_tests.ps1。
测试启动暂不自动更新，默认源码更新与授权逻辑保持；未修改原DWG、原压缩包或GitHub。
