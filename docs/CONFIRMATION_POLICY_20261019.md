# 当前规则：U1.1 人工确认

出图100% 融合测试版 U1.1：人工核对按钮与颜色统一（2026-10-19）

完整解压到新的独立文件夹，启动 CAD-100.exe 或“启动出图100%.cmd”。继续使用有效授权。
在同一软件中保留原批次处理，并从左侧进入目录校对。

这次的变化
1. 取消左侧勾选框，“未确认/已确认”按钮放在清单最右侧、原“详情”的位置，列名“人工核对”。
2. 所有尚未人工核对的黄色差异都计入顶部“待人工核对”，不再只统计关联冲突。
3. 文件名、图号、图名保持白色，仅核对结果文字变色；不再给整行铺黄色或把全行文字变黄。
4. 黄色项目必须人工确认后才进入修改计划。点击右侧“未确认”可确认明确项目；点击“已确认”可取消本行确认。
5. “确认全部明确项”一次确认当前可确定的修改，跳过冲突、读取失败、缺少属性等受阻项；明确选择保留/跳过的项目不会被重新纳入。
6. 不确定项先在下方选择正确目录行，再确认该行。仅选择目录关联不等于批准写入。
7. 已确认差异用浅蓝色结果文字保留差异与决定，不伪装为“一致”。原本一致项直接显示已确认，无须逐条点击。

04模板预期
首次扫描：图签总数10，可处理4，待人工核对6，失败0；修改计划0。
点击确认全部明确项：可处理9，待人工核对1，失败0；修改计划5。
标准园路选择 L-P-DT-002 后仍须确认；确认后可处理10、待人工核对0，计划6（4个图名、2个图号）。
“可处理”包含无需修改的一致项及已确认项目；保留/跳过不产生修改计划，实际修改数量另行显示。
读取失败单独统计，不能靠确认按钮自动放行。

阶段边界
“已确认”表示已核对/已确定处理决定，不表示DWG已经生成或验收通过。
目录仍处第二阶段：“开始处理”只保存本次批次确认计划，“打开输出文件夹”打开核对记录，不生成新的DWG。
原批次处理DWG输出功能保留，两种模式的字段与计划分开。源图、字号和位置的真实输出保护仍待目录写入阶段验收。

旧记录与恢复
旧版自动勾选草稿不含人工确认记录，不能直接恢复为已确认。本版会提示重新核对，不静默迁移。
新草稿会保存每项确认、保留、跳过决定；源文件或目录变化后仍需重新扫描核对。
确认、取消确认或修改目录关联会清空旧批次提交记录，防止旧计划被误用。
